# هوشیار POS — هستهٔ API

به درخواست کاربر، رابط کاربری مشترک برنامه از سورس فعال حذف شده است. این مخزن در وضعیت فعلی **نسخهٔ وب، PWA، صفحهٔ سفارش‌گیری یا فایل APK/نصاب قابل‌استفاده ارائه نمی‌کند**. سرور Node.js باقی‌مانده فقط API همگام‌سازی و چاپ شبکه‌ای است.

> حذف رابط مشترک باعث می‌شود پوسته‌های Android و Windows موجود در سورس فعلی نتوانند رابط فروش را بارگذاری کنند و buildهای قابل‌استفاده تولید نمی‌شود. نصب‌های قدیمی که رابط را از قبل داخل دستگاه دارند، می‌توانند در صورت نیاز همچنان به API سازگار متصل شوند.

## هستهٔ سرور

- `server.js` — فقط APIهای `/api/health`, `/api/sync` و `/api/print`؛ هیچ فایل HTML/CSS/JavaScript سرو نمی‌کند.
- `backend/node/sync-store.js` — ذخیره‌سازی versioned و idempotent در MySQL/MariaDB یا SQL Server.
- `.env.example` — نمونهٔ متغیرهای محیطی؛ مقدار واقعی محرمانه در آن قرار ندهید.
- `DEPLOY-NODE.md` — راهنمای نصب سرور API روی هاست Node.js.

## اجرای محلی و تست

نیازمند Node.js 18 یا جدیدتر:

```sh
npm ci
npm test
SYNC_API_TOKEN="$(openssl rand -hex 32)" HOST=0.0.0.0 PORT=3000 npm start
```

سرور عمداً رابط وب ندارد؛ درخواست `/` پاسخ 404 می‌گیرد. برای همگام‌سازی باید دیتابیس و متغیرهای `SYNC_DB_*` مطابق `.env.example` تنظیم شوند.

## یادداشت پلتفرم

فایل‌های بومی Android و Electron هنوز در مخزن به‌صورت پوسته/کد پل سخت‌افزار باقی مانده‌اند، اما رابط مشترک حذف شده است؛ بنابراین آن‌ها در وضعیت فعلی برنامهٔ POS قابل‌استفاده‌ای نمی‌سازند. به‌روزرسانی دوبارهٔ رابط، کار جداگانه‌ای است.
